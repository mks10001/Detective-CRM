## 💡 为什么选择桌面单机版 (.exe)？

商战博弈中的高端客户线索（如家庭软肋、决策偏好、隐秘人脉）属于**极高敏核心商业资产**。公有云 SaaS 存在泄密、被爬取或平台封禁的风险。

* **100% 本地离线**：无需配置服务器，断网环境全功能流畅运行。
* **零数据上传**：所有客户档案、观察笔记、复盘日志全部加密沉淀于本机磁盘。
* **绿色便携**：解压即用或单文件启动，不写混乱注册表，支持随身 U 盘携带。

## ✨ 核心功能亮点

* **🕵️ 暗黑特工 HUD 操控界面**
  * 赛博机密档案质感，高信息密度、低干扰布局，带来沉浸式分析与记录体验。
* **🧩 模块与条目无限自定义**
  * 预设 5 大专业情报维度，各模块均支持**自由增删条目**。
  * 支持**动态创建全新的独立情报模块**，完美适配投融资、大客户销售、猎头、政企拓展等不同赛道。
* **双轨制情报日志演变**
  * **【观察日志】**：碎片线索搜集（朋友圈、二手传闻），自动拆解为“客观事实”与“意图推论”。
  * **【接触日志】**：真实会面深度复盘，沉淀破冰利器、核心诉求及下一步（Next-Step）作战行动。
* **🏷️ 特工画像标签与战备状态**
  * 标签化管理客群特征（如：普洱老生茶、决策雷厉风行、女儿钢琴八级），全局关键词即时检索。
* **🛡️ 隐私防窥模式**
  * 一键模糊化遮罩核心敏感数据（电话、家庭住址、关键软肋），有效防止在公共场所被窥屏。
