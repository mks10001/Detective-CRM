## 📖 项目简介 (Overview)

传统 CRM 往往只记录冷冰冰的“职位、电话、拜访打卡”，忽视了商业决策背后的人性弱点、隐秘偏好、家庭牵绊与行为习惯。

**客户全景情报局（Detective CRM）** 是一款专为**高端大客户销售（ToB/Key Account）、猎头合伙人、高净值顾问及独立投资人**设计的特工级客户管理系统。通过碎片化线索搜集、事实与推论分离、同心圆关系链挖掘，帮助你在商战博弈中洞察先机。

## ✨ 核心特性 (Key Features)

* **🕵️ 暗黑特工 HUD 视觉体系**
  * 赛博机密档案风格，高对比度信息展示，告别枯燥的行政表格。
* **🧩 极致的模块化与自定义扩展**
  * 支持在任意预设模块下**无限制动态新增/删除字段**。
  * 支持**一键创建全新自定义情报模块**，完美适配各行业特异性需求。
* **双轨制情报日志（模块 5）**
  * **观察日志（旁路推演）**：记录朋友圈动态、二手传闻、碎片线索，并支持提取“事实”与“推论”。
  * **接触日志（直接互动）**：记录面谈复盘、客户真实诉求、破冰点以及明确的 Next-Step 行动项。
* **🏷️ 动态画像标签与作战预警**
  * 支持快捷注入客户偏好标签；内置“长期未跟进”警报与沉睡状态指示灯。
* **⚡ 极简轻量，开箱即用**
  * 单文件 HTML 设计（Single Page Application 原型），无构建环境依赖，双击浏览器即刻运行。
